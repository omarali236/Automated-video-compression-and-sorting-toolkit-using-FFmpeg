# Video-Compression-Toolkit
 Video Processing Toolkit:
أهلاً بك في "مفرمة الفيديوهات". هذا المستودع يحتوي على أقوى السكريبتات لأتمتة ضغط الفيديوهات وفرزها، سواء كنت بتستخدم الموبايل (Termux) أو الكمبيوتر (Windows).

# android (Termux)
هذه السكريبتات مصممة لتعمل بأقصى سرعة باستخدام المعالجة البرمجية للهاردوير (Hardware Acceleration) المدمجة في موبايلك.

الخطوة الصفرية: تجهيز البيئة
قبل تشغيل أي سكريبت، لازم تفتح Termux تقدر تنزله من f droid وتنفذ الأوامر دي بالترتيب عشان تحدث الحزم وتدي الصلاحيات:
# 1. تحديث البكجات
pkg update && pkg upgrade -y

# 2. تنزيل FFmpeg
pkg install ffmpeg -y

# 3. إعطاء صلاحية الوصول للملفات (اضغط Allow لما تظهرلك)
termux-setup-storage 
بعد مده ستخدم سكربت مكتوبه av1 لو هاتف بيدعم 
استعمل hevc اسرع 

 # (Windows)
لو بتفضل تستخدم قوة معالج الكمبيوتر، عندك أداتين هنا:

1. Smart Compressor (compress.bat) cpu
بيستخدم كوديك x265 مع إعدادات ذكية لتقليل الحجم مع الحفاظ على الجودة.  

بينظم شغلك تلقائياً في فولدر اسمه Finished.  

بيعمل تسمية تلقائية للملفات الأصلية بـ _Original لو كانت أصغر من النسخة المضغوطة.  

2. Video Sorter (filter.bat) 
أداة عبقرية بتستخدم الـ ffprobe عشان تعرف الكوديك بتاع كل فيديو عندك.  

بتنظم الفيديوهات تلقائياً في فولدرات بناءً على نوع الكوديك (مثلاً كل فيديوهات الـ H264 في فولدر
# سكربتات windows cpu 
هحاول برضو اسيب لك لل gpu لسرعه 
# كل مجهودك ممكن يبقي تعديل ال path بتاع كل ملف ال input , output 
# شرح سكربتات 
كريبت الفلتر (VideoSorter.bat) 📂طريقة العمل: السكريبت بيعمل "فحص" لكل الفيديوهات اللي في نفس الفولدر اللي هو فيه حالياً.  النقل: بيعرف الكوديك عن طريق ffprobe وبيمسك كل فيديو ينقله (move) لفولدر خاص باسم الكوديك ده (زي H264 أو HEVC) جوه فولدر رئيسي اسمه Sorted_Videos.  النتيجة: مكتوب صح جداً ومنظم. 
2. سكريبت ضغط الكمبيوتر ( Compress cpu.bat) 💻المكان: بيضغط أي فيديو موجود في نفس الفولدر اللي السكريبت شغال فيه.  المخرجات: بيعمل فولدر اسمه Finished ويحط فيه النسخ الجديدة.  الذكاء: لو النسخة الجديدة طلعت أكبر، بيمسحها وينسخ الفيديو الأصلي لمجلد Finished ويسميه _Original.  3.
