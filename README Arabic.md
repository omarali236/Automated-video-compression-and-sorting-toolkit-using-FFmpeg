# Video-Compression-Toolkit
 Video Processing Toolkit:
أهلاً بك في "مفرمة الفيديوهات". هذا المستودع يحتوي على أقوى السكريبتات لأتمتة ضغط الفيديوهات وفرزها، سواء كنت بتستخدم الموبايل (Termux) أو الكمبيوتر (Windows).

# android (Termux)
هذه السكريبتات مصممة لتعمل بأقصى سرعة باستخدام المعالجة البرمجية للهاردوير (Hardware Acceleration) المدمجة في موبايلك.

قبل تشغيل أي سكريبت، لازم تفتح Termux تقدر تنزله من f droid وتنفذ الأوامر دي بالترتيب عشان تحدث الحزم وتدي الصلاحيات:

# 2. تنزيل FFmpeg

# 3. إعطاء صلاحية الوصول للملفات (اضغط Allow لما تظهرلك)

1. PC Compress  cpu

# شرح الملفات 
1. سكريبت الفرز (VideoSorter.bat)
طريقة العمل: يقوم السكريبت بعمل "فحص" شامل لكل الفيديوهات الموجودة في نفس الفولدر الذي يعمل فيه حالياً.  

النقل: يستخدم أداة ffprobe للتعرف على كوديك الفيديو، ثم يقوم بنقله (move) تلقائياً إلى فولدر يحمل اسم الكوديك (مثل H264 أو HEVC) داخل مجلد رئيسي يسمى Sorted_Videos.  

النتيجة: سكريبت منظم جداً يساعدك في ترتيب مكتبة فيديوهاتك بضغطة زر.  

💻 2. سكريبت ضغط الكمبيوتر (Compress cpu.bat)
المكان: يقوم بمعالجة وضغط أي فيديو موجود في نفس المجلد الذي يحتوي على السكريبت.  

المخرجات: ينشئ مجلداً جديداً باسم Finished ويضع فيه جميع النسخ المضغوطة.  

الذكاء الاصطناعي: إذا وجد السكريبت أن النسخة الجديدة حجمها أكبر من الأصلية، يقوم بمسحها فوراً وينسخ الفيديو الأصلي لمجلد Finished مع تسميته بـ _Original لضمان عدم ضياع الجودة.  

📱 3. سكريبتات الأندرويد (.sh)
تعتمد نفس الفكرة الذكية الموجودة في سكريبتات الكمبيوتر، ولكنها مخصصة لبيئة Termux وتستغل الـ GPU الخاص بالموبايل لضمان أسرع أداء ممكن.
